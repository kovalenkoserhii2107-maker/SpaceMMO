# Space Strategy MMO - Developer Guidelines

## Контекст проекта
Мы создаем браузерную мультиплеерную экономическую стратегию в сеттинге космоса. 
- Backend: Node.js, TypeScript, Socket.IO.
- Database: PostgreSQL (Prisma ORM).
- Frontend: HTML/JS/CSS (SPA, REST API + WebSockets).
- Инфраструктура: Docker-контейнеризация.

## Главное правило (Итеративность)
- ЗАПРЕЩЕНО писать код для будущих этапов.
- Разработка строго поэтапная. 
- Завершив задачу: убедись, что код компилируется, остановись и запроси ревью и тестирование. Дождись утверждения.

## Правила архитектуры
1. Изоляция Game Loop: логика серверного тика в отдельном модуле, не блокирует API.
2. Типизация: строгий TypeScript, интерфейсы для Socket.IO.
3. База данных: изменения структуры только через `npx prisma migrate dev`.
4. Безопасность: расчеты (бой, добыча) строго на сервере.
