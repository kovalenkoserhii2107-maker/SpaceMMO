# Стресс-тесты экономики и логистики

Скрипты бьют по живому API и проверяют, что эксплойты закрыты.
Запускать при работающем dev-сервере.

```bash
node tests/auth.mjs
node tests/stress-market-fleet.mjs <файл-с-ид.json>
node tests/stress-races.mjs <файл-с-ид.json>
node tests/syndicates.mjs <файл-с-ид.json>
```

`auth.mjs` работает без конфигурации: он сам регистрирует временные аккаунты.

Файл с идентификаторами для стресс-тестов — JSON вида:

```json
{
  "admiralEmail": "...", "admiralPassword": "...", "admiralBase": "...",
  "pilotEmail": "...", "pilotPassword": "...", "pilotBase": "...",
  "hubId": "..."
}
```

Тесты сами проходят авторизацию и получают JWT. Нужны два командира
с деньгами, товаром на складе хаба и кораблями на базе. Пароль легаси-аккаунту
задается скриптом `npm run legacy:password -- <позывной> <пароль> [email]`.

Покрытие:
- `auth.mjs` — регистрация, вход, защита игровых роутов, онбординг командира,
  уникальность позывного, смена пароля и заглушки OAuth.
- `syndicates.mjs` — матрица прав ролей (участник не может одобрять заявки,
  исключать и распускать; офицер разбирает заявки, но не правит составом),
  общий банк с атомарными пожертвованиями и дипломатия альянсов.
  Синдикаты в конце распускаются, стенд возвращается в исходное состояние.
- `stress-market-fleet.mjs` — валидация ордеров и сделок (отрицательные и дробные
  значения, Infinity, текст, превышение баланса), гонки залога товара и криптогривны,
  аномальные вылеты флота.
- `stress-races.mjs` — конкурентное частичное исполнение ордера, двойная отмена,
  два ордера на грани баланса.
