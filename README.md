# Space Strategy MMO

Браузерная мультиплеерная экономическая стратегия в сеттинге космоса: колонии на планетах,
добыча и энергобаланс, дерево технологий, верфь, логистика флота между системами,
биржа за криптогривну, синдикаты с общим банком, PvE-экспедиции, колонизация
свободных планет, рейтинг по вложенным ресурсам и раундовые бои со скорострелом
и боевыми технологиями.

Все расчеты — на сервере. Клиент только рисует состояние и отправляет намерения.

**Стек:** Node.js + TypeScript (strict, ESM) · Express 5 · Socket.IO ·
PostgreSQL (Prisma 7 + `@prisma/adapter-pg`) · `jose` для проверки `id_token`
Google · HTML/JS/CSS без сборщика · Docker.

## Локальный запуск

Нужны Node.js 24 (как в `Dockerfile`) и доступная база PostgreSQL (подойдет Neon или локальный Postgres).

```bash
npm install
```

Скопируй пример окружения и заполни его:

```bash
cp .env.example .env
```

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `DATABASE_URL` | да | строка подключения к PostgreSQL |
| `JWT_SECRET` | в production | секрет подписи токенов сессии |
| `PORT` | нет | порт сервера, по умолчанию 3000 |
| `GOOGLE_CLIENT_ID` | нет | client id приложения Google. Пустой — кнопки входа через Google просто нет. Секрет не нужен: для проверки `id_token` хватает client id |
| `AUTH_EXPOSE_RESET_TOKEN` | нет | отдавать код смены пароля прямо в ответе API. Только для стенда: роут открытый, и с этим флагом любой, кто знает чужой email, заберет аккаунт. В production игнорируется |

Примени миграции, сгенерируй галактику и подними dev-сервер:

```bash
npx prisma migrate dev
```

```bash
npm run generate
```

```bash
npm run dev
```

Клиент откроется на http://localhost:3000 — там же регистрация, создание командира
и выдача стартовой колонии.

### Docker

```bash
docker build -t space-mmo . && docker run --env-file .env -p 3000:3000 space-mmo
```

## Фичи

**Аккаунт и командир.** Регистрация и вход по email с паролем (scrypt с солью,
сравнение постоянным по времени), сессия — JWT: один и тот же токен для REST
и для рукопожатия WebSocket. Смена пароля одноразовым кодом с истечением; ответ
одинаков для существующего и несуществующего email. Код смены пароля наружу
не отдается: роут открытый, и вернуть код в ответе значит раздать любой аккаунт
тому, кто знает адрес владельца. На стенде это включается флагом
`AUTH_EXPOSE_RESET_TOKEN=true`, в production он игнорируется. Из внешних провайдеров
оставлен один — Google. Кнопку рисует Google Identity Services, `id_token`
проверяется на сервере по JWKS: подпись, издатель, срок, `aud` и обязательный
`email_verified`. Без `GOOGLE_CLIENT_ID` кнопки нет вовсе. Apple и Facebook
убраны намеренно — первый требует платной подписки и ротации секрета раз
в полгода, второй ревью приложения с непредсказуемым сроком.

Аккаунты по совпавшему email не связываются: email при регистрации не проверяется,
поэтому кто угодно мог бы заранее занять чужой адрес и остаться в аккаунте после
того, как владелец войдет через Google. Аккаунт ищется по паре «провайдер + `sub`»,
а на занятый email вход через Google отвечает отказом с объяснением. Учетная запись отделена от игровой
личности: `User` отвечает за вход, `Commander` — за позывной, аватар, криптогривну
и счетчики боев. Достижения («Первый шаг», «Архитектор», «Гроза пиратов») выдаются
идемпотентно после сохранения состояния.

**Ресурсы.** Руда (основной строительный материал), Полимеры (электроника
и высокие технологии), Плазма (топливо и реагент), Антиматерия (топливо гиперпрыжков)
и Криптогривна как валюта. У каждого ресурса своя SVG-иконка: в интерфейсе рядом
с цифрой стоит иконка, а название остается в подсказке — так строки стоимости и
балансов читаются быстрее.

**Иллюстрации.** Карточка начинается с обложки: картинка объекта, под ней название,
а еще ниже метка — уровень, «В ангаре: 3» или «На позиции: 4». Метка стоит отдельной
строкой, а не рядом с названием: в строку они не помещаются, и «Колониальный транспорт»
рвался по слогам на три строки. Остальное содержимое идет ниже на всю ширину, поэтому
сетка карточек не зависит от размера картинки и сворачивается в одну колонку на телефоне.
Растровые иллюстрации лежат в `public/assets/` — `buildings/`, `ships/`, `defense/`,
`tech/` для карточек и `planets/`, `systems/`, `bg/` для карт — и называются по типу
объекта в нижнем регистре (`ore_mine.webp`). Обложка карточки —
строгий квадрат, под ним название, уровень и стоимость; карточки в ряду держат
одну высоту, кнопка прижата к низу.
Пока файла нет, на месте баннера стоит заглушка с инициалами — верстка от этого
не ломается, и карточки не прыгают, когда картинка появляется.
Список ожидаемых файлов — в `public/assets/README.md`.

**Раскладка интерфейса.** Экран разложен на три постоянные зоны и рабочую середину.
Сверху закрепленная шапка: командир с тегом синдиката и переключатель колоний
с координатами `X:Y:орбита`, по центру ресурсы (руда, полимеры и плазма делят лимит
склада и на пороге желтеют, а на полном краснеют), справа центр связи с бейджем
непрочитанного и выход. Слева меню разделов по группам: развитие, армия, командование,
операции, инструменты и — только администратору — сервер. Справа сводка, которая
появляется на картах: карточка планеты, отправка флота и очередь полетов с таймерами.

Над панелями стоит паспорт активной базы в три колонки: портрет планеты тем же артом,
что и на карте, адрес и склад слева, богатство недр посередине, гарнизон справа.
Богатство показано не голым множителем, а полосой со шкалой и словесной оценкой
от «скудно» до «изобилия»: у множителя нет ни нуля, ни потолка, и сравнить его
не с чем. Ожидание везде одно и то же: стройка, исследование, верфь и оборона
показывают название, время до конца, полосу и строку деталей.

На узком экране раскладка складывается ступенями: правая сводка уходит под контент,
строка ресурсов переезжает на вторую строку шапки, а на телефоне меню превращается
в выезжающую панель с бургером и карточки встают в одну колонку.

**Темп игры.** Экономика рассчитана на месяц до полного открытия контента:
первая сессия 30–60 минут, дальше несколько коротких заходов в день. Добыча
растет медленнее цены уровней, время постройки идет по степенному закону —
первые уровни ставятся за минуту-две, поздние занимают часы и сутки. Главные
ворота месяца — наука: поздние уровни технологий изучаются днями. Флот при этом
основная инвестиция: эскадра из двадцати линкоров стоит суток добычи, поэтому
терять ее больно, а базу хочется проверять.

Опорные точки: истребитель — первый час, крейсер — вторые сутки, фрегат —
четвертые, колонизация и бомбардировщик — вторая неделя, линкор — третья,
авианосец и «Перун» — конец месяца.

**Колонии и экономика.** Планеты с индивидуальными коэффициентами руды, полимеров,
плазмы и инсоляции. Здания тратят энергию: при дефиците добыча всех шахт падает
пропорционально (`efficiency = output / usage`). Дерево из технологий с иерархией
требований — энергетика, вычислительная техника, оружейная, щитовая и бронебойная
технологии, горное дело, реактивный двигатель, гиперпространственная физика,
гипердвигатель, астрофизика. Верфь строит корабли
и стационарную оборону собственными очередями.

**Тиковый движок.** Стройка, исследования и очереди считаются от абсолютных меток
времени: процессы идут, пока игрок офлайн, и переживают перезапуск сервера. Добыча
за офлайн (до 24 ч) начисляется по отрезкам между завершениями таймеров. Тик раз
в секунду, пакетная запись в БД, push состояния клиенту по WebSocket.

**Карта системы.** Круговая микро-карта: звезда или черная дыра в центре, планеты
на концентрических орбитах, торговый хаб на своем кольце и точка выхода в глубокий
космос снаружи. Тела берут картинки из `assets/planets/` по биому, пока файла нет —
цветной круг. Размер планеты зависит от ее типа: газовый гигант крупнее всех,
скалистый огрызок мельче всех, и по карте видно, где добыча богаче, еще до разведки.
Орбиты начинаются у самой звезды, а их шаг зависит от числа планет: система из трех
выглядит компактной, из пяти — просторной, и тела никогда не наезжают друг на друга.
Название стоит под планетой, а своя колония отмечена не кольцом, а зеленой точкой
под подписью. Звезда, черная дыра, туманность и станция хаба не обрезаются кругом
и растворяются в фоне через `mix-blend-mode`, планеты остаются непрозрачными шарами
с круглой обрезкой. Фон карты — тайл звездного поля под сильным затемнением: яркая
подложка съела бы свечение тел.

**Карта галактики.** Системы нарисованы миниатюрами галактик и туманностей
из `assets/systems/` — четыре варианта, и вариант выбирается по координатам, чтобы
система не меняла вид при каждой перерисовке. Шаг сетки одинаков по обеим осям,
а размер холста считается от разброса координат: расстояние между системами на карте
соответствует расстоянию между ними в игре, а не форме панели. Клик по системе
открывает ее микро-карту — с тем же туманом войны, что и своя.

**Информация при наведении.** Рядом с телом разворачивается HUD-карточка: сначала
от него протягивается линия, затем на ее конце проявляется панель — около 0.4 секунды
на все. Цифры разложены по сетке, а не в столбец, поэтому карточка не растет вниз
на пол-карты; постройки в ней опущены — полный разбор открывается кликом в панели
справа. Наведение на звезду показывает ее класс, температуру и число планет;
у черной дыры температуры нет. На сенсорном экране карточка не показывается:
наведения там нет, а панель закрыла бы саму карту.

**Туман войны и логистика.** Своя планета видна целиком и в реальном времени, чужая —
только название, орбита, тип и размер; после прилета зонда сохраняется стареющий
снимок разведки. Скорость флота задает самый медленный корабль, грузоподъемность
и топливо считаются по составу и времени в пути. Руда, полимеры и плазма делят один
трюм: плазма и топливо, и товар, поэтому колонии перебрасывают его между собой
обычным транспортом. Внутри системы флот идет на плазме, между системами —
гиперпрыжком на антиматерии, и прыжок требует «Гипердвигателя». Топливо берется
за дорогу туда и обратно; рейс без возврата платит только за один конец. Прилеты
обрабатываются глобальным сканом: груз доходит и корабли возвращаются, даже если
обе стороны офлайн.

**Отправка флота.** Цель выбирается кликом по круговой карте или вводом координат
«система X:Y и орбита» — по ним цель находится и в чужой системе, которую карта еще
не открывала. Дальше панель ведет по трем шагам.

Первый — действие: не выпадающий список, а меню кнопок. Действий у цели три-четыре,
они разные по смыслу, и от выбора зависит остальная форма; в свернутом списке игрок
не видит, что вообще можно сделать с планетой. Набор решает не наличие владельца,
а состояние планеты, и состояний четыре:

| Планета | Действия |
| --- | --- |
| своя колония | транспортировка, дислокация |
| чужая колония | атака, отправить груз или помощь, шпионить зондом |
| свободная | разведка, основать колонию (с основателем в составе) |
| не разведана | разведка, атака, транспорт, колонизация |

Последний случай отдельный: у неразведанной планеты владелец скрыт туманом войны,
и пустой владелец там не значит «свободна». Пункты в ней не мертвые, а именно
неизвестные — игрок может знать о планете от союзника, и сервер откажет, только
если догадка не подтвердится. По умолчанию подставляется безопасное действие,
а не первое в списке: у чужой колонии первая — атака, и она объявляет войну.

Второй шаг — состав: поля по классам кораблей с остатком на базе, кнопки «Выбрать все»
и «Очистить», плюс сохраненные шаблоны. Третий — груз и расчет маршрута: дистанция,
время, топливо с остатком на складе и занятость трюмов; нехватка подсвечивается
до вылета. Справа же очередь активных полетов с таймерами до прибытия.

Миссии: транспортировка, разведка зондом, атака, дислокация, доставка и вывоз
на хабе, экспедиция, переработка обломков и колонизация. Переработка появляется,
только когда над планетой висит поле и в составе есть переработчик.

**Война объявляется атакой.** Отдельный поход в раздел дипломатии больше не нужен:
если войны с целью нет, вылет объявляет ее сам. Членство в синдикате личную войну
не запрещает — запрет приводил к тому, что кнопка «Атака» у половины игроков давала
отказ вместо боя. Вместо запрета предупреждение: предпросмотр маршрута говорит,
что войны нет и что синдикат цели может ответить всем составом. Считает его сервер —
только он знает дипломатию, а отдавать ее клиенту ради строки текста незачем.

**Помощь союзнику.** Транспорт на чужую колонию можно отправить с флажком
«без возврата»: тогда у получателя остается не только груз, но и сами корабли —
так передают флот. Обычный рейс, как и раньше, выгружает груз и возвращается.
Атака и разведка возвращаются всегда: флот, брошенный у чужой колонии,
достался бы противнику даром.

**Колонизация.** Расширяться можно одноразовым «Колониальным транспортом»: он
садится на свободную планету и разбирается на первую инфраструктуру новой базы.
Рейс односторонний — конвой и груз остаются колонии, обратно летит только тот,
кто не понадобился. Сколько колоний можно держать, задает «Астрофизика»: одна
на старте и еще одна за каждые два уровня. Свобода планеты и наличие слота
проверяются дважды — при вылете и на прилете, потому что за время полета планету
могли занять. Сорвавшийся рейс возвращает флот целиком и даром: обратный путь
при вылете не оплачивался. Причина всегда приходит письмом.

**Арсенал.** Двенадцать классов кораблей и пять классов обороны с украинскими
позывными. Легкая линия — «Око», «Чайка», «Чумак», «Сокіл»; средняя —
«Гайдамака», «Отаман», «Характерник»; лейтгейм — «Булава», «Гетьман» и «Січ».
Оборона идет от массового «Града» через «Промінь» и «Скіф» к батарее «Сварог»
и ультимативному излучателю «Перун».

Роли разведены матрицей скорострела: тяжелый истребитель косит мелочь, крейсер —
истребителей, линкор — крейсера и бомбардировщики, авианосец — весь легкий
и средний класс, а бомбардировщик разбирает планетарную оборону очередями.
По «Перуну» очереди нет ни у кого: ультимативную установку берут только массой.

Сила «Перуна» — не корпус, а щит: 3000 восстанавливаются к каждому раунду,
и эскадра с суммарным залпом ниже этого числа не наносит ему вообще ничего.
Восемь линкоров бьют на 8000, но теряют по кораблю в раунд и к шестому уже
не пробивают щит: бой кончается ничьей, а она остается за защитником. Порог
пробоя — двенадцать линкоров на один излучатель.

**Технологии скорости.** «Робототехника» ускоряет постройку зданий и сборку
кораблей с обороной — на исследования она не влияет, там работает уровень
лаборатории. «Сжатие времени» открывается в самом конце дерева и каждым уровнем
сокращает вдвое вообще все сроки: стройку, верфь, оборону и науку. Плата —
энергия: каждый следующий уровень потребляет вдвое больше предыдущего,
а дефицит энергии режет добычу всей базы. На средней энергетике включенное
сжатие второго уровня роняет доход втрое, на развитой не отнимает ничего —
поэтому ускорение окупается только тому, кто заранее вложился в станции.

**Антиматерия и аномалии.** «Фабрика антиматерии» — самая дорогая постройка
с огромным расходом энергии, синтез идет на порядки медленнее обычной добычи.
Аномалия «Черная дыра» в 1-2 системах дает «Искажение времени»: синтез антиматерии
+50%, стройка (включая верфь) и исследования на 30% дольше.

**Биржа и криптогривна.** Торговый хаб — нейтральная станция на орбите у звезды.
Товар попадает на склад только транспортным флотом, что не влезло — возвращается
домой в трюмах. Биржевой стакан: ордера на покупку и продажу руды и полимеров,
частичное исполнение, залог товара и денег. Сделки идут одной транзакцией БД
и пишутся в журнал.

**Синдикаты.** Название, тег, лидер и состав; основание стоит криптогривну. RBAC:
лидер и офицеры разбирают заявки, состав и роспуск — только лидер, офицер исключает
лишь рядовых. Передача лидерства делает старого лидера офицером одной транзакцией.
Общий банк: пожертвование списывается со счета и зачисляется в банк атомарно,
каждая операция попадает в журнал, при роспуске остаток возвращается лидеру.
Дипломатия альянсов: члены синдиката не объявляют личных войн — войну и мир
объявляют лидер или офицеры сразу вражескому синдикату.

**Рейтинг.** Счет командира — это ресурсы на руках плюс стоимость всего,
что построено и не потеряно: флот (в том числе тот, что сейчас в полете),
оборона, здания и технологии. Здания и наука считаются суммой по всем уровням
с первого: десятый уровень стоил владельцу и всех девяти предыдущих. Считается
наличие, а не история трат — потерянный в бою флот из счета уходит, иначе
таблица превратилась бы в список тех, кто дольше играет. Все ресурсы идут
один к одному по единицам. Рядом с таблицей своя строка с разбивкой по
слагаемым: по ней видно, чем игрок силен. Синдикаты ранжируются суммой
состава и средним счетом участника — по второму видно, синдикат силен
или просто велик.

**Экспедиции (PvE).** Вылет в «глубокий космос» — абстрактную 16-ю позицию, которая
есть у каждой системы. «Астрофизика» задает число одновременных экспедиций, повышает
находки и дает шанс уйти от засады, а заодно открывает колониальный транспорт
и слоты под колонии. Событийный движок бросает кубик по весам: мертвая
тишина, заброшенный груз, уклонение или бой с пиратами. Генератор случайных чисел
передается снаружи, поэтому любой исход воспроизводим в тестах.

**Хранилища и лимит склада.** «Склад ресурсов» задает общий лимит на руда,
полимеры и плазма: базы копят тоннаж, а не три независимые кучи. Уровень 0 — это
колониальный резерв на 5 000, уровень 1 дает 10 000, дальше вместимость растет в 1.5 раза
за уровень. Когда склад полон, добыча останавливается полностью — и в тике, и в догоне
офлайна, так что неделя отсутствия не приносит больше, чем влезает. Антиматерия хранится
отдельно и под лимит не попадает. Переполнить склад сверх лимита все же можно — возвратным
рейсом, трофеями экспедиции или отменой биржевого ордера; такие ресурсы не пропадают,
но и не защищены.

**Поля обломков.** Бой оставляет экономический след: 30% стоимости уничтоженных
кораблей — и нападавшего, и защитника — оседает обломками на орбите планеты.
Разбитая оборона обломков не дает: она восстанавливается на месте, а не улетает
в поле. Поле видно всем игрокам и не скрывается туманом войны, поэтому
за крупным полем начинается гонка. Собрать его может только «Переработчик» —
безоружный корабль с трюмом на 20 000, который ползет медленнее всех и жжет плазма
как десять транспортов. Миссия «Переработка» доступна над любой планетой, даже чужой
и необитаемой. Обломки достаются тому, чей флот долетит первым: списание атомарно,
и опоздавший либо добирает остаток, либо возвращается пустым — о чем прямо пишет
отчет, иначе исчезнувшее поле выглядело бы багом.

**Панель администратора.** Отдельная роль `ADMIN` на учетной записи и защищенный
раздел `/api/admin/*`: список командиров с поиском по позывному, полный стейт игрока
и принудительная правка ресурсов, криптогривны, зданий, технологий, флота и обороны.
Значения выставляются целиком, а не прибавляются — в форме уже стоят текущие числа,
и повторная отправка не удваивает выданное. Каждое изменение пишется в лог сервера.
Вкладка появляется только у администратора, но доступ решает сервер: запрос обычного
игрока получает 403 независимо от интерфейса. Роль выдается скриптом
`npm run admin:grant -- <email>`, игрового пути к повышению прав нет.

Сверху сводка по серверу: сколько игроков сейчас в сети (по живым сокетам, а не
по времени последнего входа), сколько заходило сегодня и за неделю, сколько новых,
колоний, флотов в полете и синдикатов. У каждого игрока — карточка учетной записи:
почта, способ входа, даты регистрации и последнего входа, состояние доступа.

Действия над аккаунтом отделены от правки игровых чисел: у них разные последствия,
и складывать их в одну кнопку «Сохранить» значит однажды заблокировать игрока,
поправляя ему руду. Пароль пульт не задает и не показывает — админ выдает
одноразовый код, а новый пароль игрок вводит себе сам. Блокировка закрывает вход
и игровой канал, но не трогает колонии: разблокированный находит мир таким, каким
оставил. Удаление необратимо и требует ввести позывной — каскад уносит колонии
(планеты освобождаются), флоты и синдикат, если игрок им руководил.
Администратора нельзя ни заблокировать, ни удалить. Письмо от гейм-мастера
приходит игроку отдельным типом `ADMIN`, чтобы не теряться среди автоотчетов.

**Центр связи.** Внутриигровая почта с фильтрами по типам писем. Личные сообщения
отправляются по позывному, лидер и офицеры синдиката рассылают объявление всему
составу разом. Все системные отчеты приходят сюда же: бой, разведка, экспедиция
и логистика доставляются письмами от «Центра связи». Доставка груза уведомляет обе
стороны — отправитель видит, что выгрузился, владелец колонии узнает, кто прислал
ресурсы, иначе они появлялись бы на складе молча. Флот, вернувшийся с добычей,
тоже пишет; пустой возврат молчит, о таком рейсе уже был свой отчет. Один бой дает два зеркальных письма —
атакующий читает про свои трофеи, защитник про свои потери. В шапке висит иконка
почты с бейджем непрочитанного, который обновляется через Socket.IO в момент
доставки, а не по опросу. Ящик строго адресный: чужое письмо нельзя ни прочитать,
ни удалить даже по прямому идентификатору.

**Боевой отчет.** Письмо о бое разворачивается не текстом, а полноценным отчетом:
исход (победа, поражение или ничья) глазами того, кто его открыл, место боя
с системой и орбитой, дата. Дальше итоги крупно — сколько обломков осело на орбите
и сколько ресурсов вывезено, — и потери обеих сторон таблицей: было, потеряно,
осталось, с иконкой каждого класса. Сторона, от которой ничего не осталось,
подписывается «Флот уничтожен». Тем же компонентом рисуется предпросмотр
в симуляторе, поэтому прогноз и настоящий отчет читаются одинаково.
Пораундового лога пока нет: сводки «было / стало» хватает, чтобы понять итог.

**Инструменты командира.** Боевой симулятор прогоняет любой состав атакующих против
любого флота и обороны защитника через тот же боевой движок, что и настоящий бой,
и ничего не пишет в базу: видно потери, пробитие слоев и предполагаемую добычу с учетом
хранилища и трюмов уцелевших. Состав защитника подставляется из отчета разведки одним
выбором. Шаблоны флотов — сохраненные составы («Фарм-отряд»: 10 крейсеров, 5 транспортов),
которыми заполняется форма отправки; шаблон только подставляет числа, наличие кораблей
проверяется при вылете.

**Старение разведданных.** Снимок зонда не обновляется сам, поэтому у него есть срок
годности: до часа данные свежие, от часа до суток помечаются как неточные, а после суток
сервер вообще не отдает флот, оборону и склад — остаются только уровни построек, владелец
и богатство планеты. Возраст снимка виден рядом с цифрами, чтобы атаку не планировали
по вчерашней разведке.

**Бой.** Раундовая симуляция: до шести раундов, каждый живой юнит раз в раунд бьет
по случайной цели. У юнита три характеристики — атака, щит и корпус. Щит поглощает
урон первым и восстанавливается к следующему раунду, корпус не лечится; юнит гибнет,
когда корпус уходит в ноль. Отсюда главное правило боя: одиночный слабый залп вязнет
в щите, но десять подряд продавливают его в том же раунде. Ионный фрегат снимает щиты
с двойным множителем — его роль вскрывать защиту тяжелых кораблей, а не убивать их.

Скорострел решает обратную задачу: после выстрела юнит с шансом `(N-1)/N` стреляет
снова и снова, пока очередь не оборвется, — так тяжелый корабль успевает выкосить
рой мелочи за один раунд, а не разменивать себя на нее по одной цели. Матрица
односторонняя: крейсер бьет очередью по истребителям (N=10), зондам и транспортам
(N=5), ионный фрегат — по лазерным турелям (N=8) и той же мелочи, истребитель —
по пушечным турелям (N=3). У обороны скорострела нет. Отсюда состав флота начинает
значить больше числа: крейсер уверенно берет равный по стоимости рой истребителей,
но вязнет в лазерных турелях, где тот же бюджет фрегатов проходит насквозь.

Три технологии масштабируют характеристики: оружейная поднимает атаку, щитовая —
щиты, бронебойная — корпус, каждая на +10% за уровень, и все три действуют
и на флот, и на оборону. «Энергетика» на бой больше не влияет — она осталась
экономической веткой и пререквизитом для фрегата и реактора.

Побеждает тот, у кого противник кончился; если после шестого раунда живы обе стороны —
ничья, и поле остается за защитником. Разбитая оборона восстанавливается с шансом 70%. Победивший
атакующий грабит склад по механике «сейфа»: хранилище прячет ресурсы в объеме до 90%
своей вместимости, а с уязвимого излишка сверх этого порога агрессор забирает 90%
пропорционально каждому типу ресурса — руда, полимеры и плазма одинаково. Полупустая база не теряет ничего, а забитый
под потолок склад становится осмысленным риском. Итог все так же режется трюмами
уцелевших кораблей. Отчеты показывают, куда ушел урон с обеих сторон и сколько
ресурсов спрятало хранилище защитника. Бой случаен — цели выбираются броском кубика,
и один и тот же состав дает разброс исходов; случайность вынесена в параметр `rng`,
поэтому предпросмотр в симуляторе и тесты подставляют зерно и получают повторяемый бой.

```
  game/ships.ts                 классы кораблей: стоимость, время, боевые профили
  game/defenses.ts              стационарная оборона: стоимость, время, энергия
  game/combat.ts                бой: раунды, щиты и корпус, скорострел, обломки, грабеж

  game/market.ts                вместимость складов хаба и проверки ордеров

  services/achievementService.ts каталог достижений и их выдача
  services/mapService.ts        сборка карты системы под конкретного игрока
  services/marketService.ts     биржа: ордера, сделки, склады хаба (в транзакциях)
  services/syndicateService.ts  синдикаты: роли, заявки, общий банк
  services/adminService.ts      пульт гейм-мастера: чтение и правка состояния
  services/mailService.ts       центр связи: ящик, доставка, приватность
  services/reportMail.ts        сборка текста системных отчетов (чистый модуль)
  services/simulationService.ts боевой симулятор: расчет без записи в БД
  services/fleetTemplateService.ts шаблоны флотов
  services/warService.ts        дипломатия, отчеты о боях, предупреждение перед атакой
  services/scoreService.ts      рейтинг командиров и синдикатов с кешем
  types/api.ts                  типы ответов REST
  types/socket.ts               типизированные интерфейсы Socket.IO
  scripts/                      генерация галактики, проверка формул, стенд для тестов
public/                         клиент: вход, командный центр, карты, биржа, синдикаты
                                (index.html хранит спрайты иконок и иллюстраций)
prisma/                         схема и миграции
tests/                          тесты формул на игровых модулях и стресс-тесты по живому API
```

| --- | --- | --- |
| POST | `/api/auth/register` | регистрация по email и паролю |

| GET | `/api/auth/config` | публичные настройки входа: client id Google |
| POST | `/api/auth/oauth/:provider` | вход через Google по `id_token` |
| POST | `/api/auth/password/reset-request` | запрос кода смены пароля |
| POST | `/api/auth/password/reset` | установка нового пароля |
| GET | `/api/auth/me` | текущая сессия: аккаунт, командир, аватары |
| POST | `/api/auth/commander` | создание командира (онбординг) |
| GET | `/api/state` | состояние игрока: базы, очереди, технологии, флот |

## Качество кода

- Строгий TypeScript: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
  Отдельный прогон `npm run audit` добавляет `noUnusedLocals` и `noUnusedParameters`.
- Ответы REST типизированы через `Response<...>` ([types/api.ts](src/types/api.ts)),
  события Socket.IO — через типовые контракты ([types/socket.ts](src/types/socket.ts)):
  расхождение между сервером и клиентом ловит компилятор.
- Игровые правила вынесены в чистые модули без обращений к БД, поэтому формулы
  проверяются отдельно от инфраструктуры (`npm run check:rules`).
- Экономика, бой и логистика идут транзакциями: гонки закрыты условными `UPDATE`,
  жесткий перезапуск между шагами не задваивает начисления и не теряет корабли.

Правила разработки и текущая архитектура — в [CLAUDE.md](CLAUDE.md).
